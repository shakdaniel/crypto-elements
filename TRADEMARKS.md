This project distributes the marks for **nominative use** — identifying the project, chain or
venue a mark stands for, which is what an icon in a wallet, explorer or aggregator UI does.

## Using these icons

Do:

- use a mark to identify the thing it names (a chain selector, a route, a token row);
- keep the mark legible, unmodified in shape and in the brand's colours;
- follow the owner's own brand guidelines when they publish them — they take precedence
  over anything in this repository.

Don't:

- use a mark as your own logo, favicon, app icon or social avatar;
- suggest a brand sponsors, endorses or is affiliated with your product;
- alter a mark to create a confusingly similar one, or use it in a way that
  disparages the brand;
- assume the MIT licence grants you any trademark rights. It does not.

## Fidelity

`icons/registry.json` records a `fidelity` field per icon:

- `official-geometry` — the artwork matches the brand's published mark.
- `approximate` — a hand-authored interpretation in the brand's colours, drawn for this
  project. It is not the brand's own file and should not be treated as one.

## Takedowns

If you own one of these marks and want it changed or removed, open an issue titled
`Trademark: <brand>` or email the maintainers. We will act on it promptly and without
argument — no lawyer letter required.
